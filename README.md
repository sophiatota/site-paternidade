# Guia da Paternidade 👨‍👧‍👦

O **Guia da Paternidade** é um site criado para ajudar pais a desenvolver hábitos saudáveis, superar dificuldades e se preparar para os desafios da paternidade. O site oferece dicas sobre a preparação para a chegada do bebê, os cuidados após o nascimento, a saúde emocional do pai e a construção de uma família saudável.

O objetivo é incentivar pais a reconhecer comportamentos prejudiciais, melhorar suas atitudes e se tornarem mais presentes, responsáveis e participativos na vida dos filhos!!. 💙
